# g6ct - Creative "MatrixEncoder" 7.1 -> binaural downmix
#
# Replica of CMatrixEncoderEfxMod in KSUSBAPO64.dll (Sound BlasterX G6 USB
# audio driver), expressed in EqualizerAPO's config language.
#
#   frontL = FL + 0.707*FC + 0.707*LFE
#   frontR = FR + 0.707*FC + 0.707*LFE
#   surL   = 0.786*BL + 0.619*BR + 0.875*SL + 0.485*SR
#   surR   = 0.619*BL + 0.786*BR + 0.485*SL + 0.875*SR
#   outL   = B(A(frontL)) + D(C(surL))
#   outR   = B(A(frontR)) - D(C(surR))
#
# A..D are 2nd-order all-passes (b0 == a2, b1 == a1, b2 == 1), so each branch
# is phase-only; the sign flip on the right surround is the out-of-phase
# cross-feed that puts the surround image behind the listener.
#
# Channel numbers are the device order for mask 0x63F:
#   1 FL  2 FR  3 FC  4 LFE  5 BL  6 BR  7 SL  8 SR
#
# The matrix has no preamp: it is the DLL's transfer function at unity.
# The rows sum to as much as +7.6 dB, so a hot 7.1 source can push the
# output past 0 dBFS. The G733 endpoint then engages a peak limiter
# (measured ceiling 0.9853 = -0.13 dBFS, gain flat to 0.645 at +3.8 dBFS
# over), which is what any playback chain would do. Keep the output peak
# under ~-0.15 dBFS - either with a lower source level or by adding
# `Preamp: -4 dB` above the Stage line - when the exact transfer
# function has to be measurable. See WINDOWS.md.
#
# Generated by mkconfig.py - edit the generator, not this file.
# ===========================================================================
